> [!IMPORTANT]
> Jam Reborn 6.4.0 is the final version. It no longer connects to Animal Jam; opening it only shows where to get JR. This repository is archived and won't be updated.

## How to switch to JR

1. Download **JR-Setup.exe** from the [JR releases page](https://github.com/BradysLabs/JR/releases/latest) and run it.
2. Join the [JR Discord](https://discord.gg/UvXzA2gK5W), then sign in to JR with Discord.
3. Uninstall Jam Reborn from Windows **Settings → Apps**.

## What JR adds

- **Profiles:** each profile opens in its own window, so you can play two accounts at once
- **Trading helper:** values from the Item Worth Wiki in Diamonds, with a favor scale
- **My Shop Templates:** save your shop and refill it in one click or automatically
- **Themes** and a customizable home screen
- **Anti-kick** for idle timeouts, and Discord Rich Presence
- Jam Reborn's plugins, rebuilt for JR. Plugins written for Jam Reborn keep working in JR

## About Jam Reborn

Jam Reborn was a community continuation of Jam, a modular man-in-the-middle proxy for Animal Jam Classic built with Node.js and Electron. It ran from version 5.0.1 to 6.4.0 and added the Plugin Hub, streaming mode, Adventures, Item Previewer, Glow Picker, Name Checker, Masterpiece Studio, Asset Browser, a rebuilt Packet Inspector and more. Thank you to everyone who used it, reported bugs and made plugins.

The source code stays here for reference.
